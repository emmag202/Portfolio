To publish with GitHub Pages:
1. Upload index.html and the assets folder to the root of a GitHub repository.
2. In the repository, open Settings > Pages.
3. Choose Deploy from a branch, select the main branch and /(root), then save.

The portfolio includes screenshots supplied for the dinosaur website, DineMind AI project, and Printify shop. Replace any project text or contact details before publishing if you want to make changes.
